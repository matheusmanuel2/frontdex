# 005 — Voz e texto

Status: aprovada · Depende de: 000 · Agentes: todos

## Voz

Direta, técnica e calorosa. Fala como um dev sénior que recomenda algo a um colega: diz o que é, para que serve e o que tem de diferente. Sem hype.

- pt-BR no site em português; inglês simples na versão em inglês.
- Frases curtas. Verbos concretos. Um detalhe específico vale mais que três adjetivos.
- "Você" em pt-BR.

## Descrições de recursos (40–160 caracteres)

Fórmula: **o que é + o que o distingue (detalhe concreto)**.

| Bom | Mau |
| --- | --- |
| Divide texto em linhas, palavras e letras exatamente onde o navegador quebrou, pronto para animar. | Uma biblioteca poderosa para animações de texto incríveis. |
| Terminal nativo para macOS, baseado no Ghostty, com abas verticais e avisos quando um agente precisa de você. | O melhor terminal para desenvolvedores modernos. |
| Animated React components you copy-paste, not install. | A powerful library for building beautiful UIs. |

## "Por que está aqui" (opcional, ≤ 160 caracteres)

Uma opinião de curador, honesta: em que situação este recurso é a melhor escolha. Ex.: "Sem dependências e respeita a quebra real de linha, o ponto onde os splitters comuns falham."

## Textos de interface

- Títulos de secção em dois tons: afirmação + complemento ("Recém-indexados. / Entraram esta semana.").
- Botões com verbo: "Buscar no índice", "Adicionar recurso", "Sugerir edição".
- Erros dizem o que aconteceu e o que fazer.
